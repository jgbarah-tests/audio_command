# Specifications

* HTML page, simple
* Use a speech to text model in the browser to convert speech by the user into text, which will be presentd in the page
* Use a text to speech model in the browser to convert text (the one resulting from the previous operation) into voice, which will be pushed to the speaker.
* All operations local to the browser, no API involved
* Very simple user interface: just a button (toggle) to start listening to speech, and then stop and show the text, and reproduce it as voice.
